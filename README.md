# 🔔 Reminder App

A Node.js based reminder application that schedules and automates notifications using **Cron Jobs**.

## 🚀 Features

* **Automated Reminders**: Uses scheduled cron jobs to trigger reminders at specific intervals.
* **Database Integration**: Stores reminders and user settings securely.
* **REST API**: Clean endpoints for managing reminders.

## 🛠️ Tech Stack

* **Backend**: Node.js, Express.js
* **Database**: MongoDB / SQL (Aap jo db use kar rahe hain)
* **Scheduling**: node-cron (ya cron package)
